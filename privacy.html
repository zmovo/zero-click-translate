Zero Click Translate

Privacy Policy

Last updated: 22 September 2026

Zero Click Translate is a Chrome extension that shows a translation next to text you select. It does not use accounts, logins, browsing history, or advertising.

What we process

When translation is on and you select text, the extension sends the selected text and the target language to a translation service. It also stores, on this device only: on/off state, language pair, monthly character quota, an anonymous installation id, and a short-lived auth token.

Where selected text goes

Translation is attempted in this order:

  • Our Cloud Run API https://zero-click-translate-api-475510566240.europe-west1.run.app (/register once, then /translate), which forwards text to Google Cloud Translation
  • Public Google Translate webpage endpoints, if the API is unavailable
  • MyMemory, if the Google webpage endpoints fail

Turning the extension off stops page injection. It then does not read selections or send text.

Why the extension asks for site access

Broad site access is required so the overlay can appear on the page you are reading. The extension does not scrape the rest of the page. It only uses the current selection.

What we do not do

  • Sell data
  • Use selected text for ads or profiling
  • Create user accounts
  • Run remote code from the store package
